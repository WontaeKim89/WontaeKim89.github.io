1) Hugging face에서 아래와 같이 pre-trained model을 불러와서 사용하려했다.

![](/assets/img/posts/20/1.png)

2) jupyter notebook에서 관련 repo 설치를 위해 아래 코드 입력시, "git: 'lfs' is not a git command" 오류가 발생했다.

![](/assets/img/posts/20/2.png)

3) git-lfs가 설치되어있지 않아 발생하는 문제였다. 우선 설치를 위해 homebrew가 먼저 설치되어 있어야한다.

```
MacOS (Using Homebrew)

$ brew update

$ brew install git-lfs
```

4) homebrew설치 후 git-lfs가 정상적으로 설치완료된 것을 확인할 수 있다.

![](/assets/img/posts/20/3.png)
