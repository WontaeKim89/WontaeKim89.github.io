> **서비스에 설정된 Default Git branch를 조회하고,   
> 다른 branch를 기본 branch로 변경해보자.**

**[Git Branch 조회]**

```
git branch -a
```

![](/assets/img/posts/42/1.png)

git branch가 "develop"가 default로 셋팅되어있다.

**[Git Branch 변경]**

```bash
git checkout master
```

![](/assets/img/posts/42/2.png)

"master"를 default git branch로 셋팅하였다.
